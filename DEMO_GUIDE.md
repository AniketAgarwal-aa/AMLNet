# Five-minute AMLNet demo

1. Start backend and frontend using the README commands; open `http://localhost:5173`.
2. On **Dashboard**, explain the persisted account, transaction, risk, and recent-alert totals.
3. Open **Account Investigation**, search `S001`, inspect GNN probability, blended risk, feature evidence and actual transfer history.
4. Open **Graph Explorer**. Pan/zoom the directed graph and click a red/orange node to see its score.
5. Open **Suspicious Activity** and explain the circular, rapid, fan-in, and fan-out alerts as review signals.
6. Open **Model Performance** to compare genuine held-out GCN and Logistic Regression metrics.
7. Open **Model Management** and start a retraining job; observe actual status.
